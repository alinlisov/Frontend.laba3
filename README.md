**Тема:** Блочна верстка макету сайту за допомогою HTML і CSS (Float та Flexbox).  
* **Файли:** `index.html`, `style.css`
*  Точна відтворення Photoshop-макету сайту двома методами верстки.
* **Пропорції макету:**
  * **Ширина (Ось X):** Загальна ширина $1000\text{ px}$ (від 100px до 1100px). Ліва колонка `Img.` — $250\text{ px}$ ($25\%$), права колонка `Text` — $750\text{ px}$ ($75\%$).
  * **Висота (Ось Y):** Верхній блок (`Img.` + `Text`) — $470\text{ px}$ (100px–570px), середній синій блок — $150\text{ px}$ (570px–720px), нижній жовтий блок — $130\text{ px}$ (720px–850px).
* **Реалізовані завдання:**
  1. **Завдання 1 (Float):** Побудова блочного макету за допомогою `float: left`, відсоткового задання ширин (`25%` та `75%`) та використання розширення `.clearfix::after` (`clear: both`) для відновлення потоку.
  2. **Завдання 2 (Flexbox):** Верстка того ж макету за допомогою модуля Flexbox (`display: flex`, `flex-direction: column/row`).
